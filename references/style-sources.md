# 風格研究來源（2026-11-04）
本版 30 套風格為依設計語彙原創的向量示意，不是來源專案的官方模板或授權截圖；三種頁型使用相同示例文字，便於比較。影像敘事預覽使用幾何示意，不冒充照片。
- [Slidev official themes](https://github.com/slidevjs/themes)：研究 default、seriph、bricks、apple-basic 的分類與版式。程式 MIT；其圖片與素材另為 CC BY-NC-SA 4.0，未複製其素材。
- [Marp Core themes](https://github.com/marp-team/marp-core/blob/main/themes/README.md)：研究 Default、Gaia、Uncover 的清楚、簡約與反相設計。
- [Reveal.js](https://github.com/hakimel/reveal.js)：研究網頁簡報的主題與播放控制。
- [Frontend Slides](https://github.com/zarazhangrui/frontend-slides)：研究視覺選擇流程及其現有版型；固定版本仍見 upstream-lock.json。
- [Taste Skill](https://github.com/Leonxlnx/taste-skill)：研究版面變化與密度的參數化思路，未新增執行依賴。
- [sci-present](https://github.com/arpitsingh-chem/sci-present)：研究跨 HTML／PPTX 使用共用配色的思路，未複製模板或程式。
- [Codex non-interactive mode](https://developers.openai.com/codex/noninteractive)：本機橋接使用 codex exec、stdin 與 JSONL 事件，並以本機 exec --help 核對參數。
完整風格資料與視覺規則見 ui/styles.json，每個 id 對應三張 ui/previews/ SVG。風格不是學段限制；按受眾與目的調整密度、字體及說明。
